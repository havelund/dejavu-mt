DejaVuMT

Monitors first-order past-time LTL properties (DejaVu's QTL) over an event log, using an SMT solver instead of BDDs.

Files

open… browses the repository tree (.qtl and .csv files only). Shortcuts: clicking a folder that holds exactly one spec and one log (and no subfolders) loads both; picking a spec auto-loads the only log in its folder, and vice versa; the browser reopens where you last were.

Run verifies the editors, not the files. Nothing is written to disk until you press save, which writes the pane to the (editable) path in its file bar — change the path first to save a copy.

Options

solver: Z3 (default) or CVC5 — verdicts are identical.
formula trees: per-event annotated formula trees (see below).
strong: solver-backed simplification — cleaner formulas, much slower.
weak: no simplification at all — shows the raw recurrences; short traces only.
gc: periodic collection of dead value-terms (every 50 events).

Results

Click an event row to show/hide its formula trees (expand all / collapse all in the summary line); events that violate a property are marked red and shown expanded.

In a tree, each node's unlabeled annotation is its stored formula; where a node's exported value differs — timed operators and H — it follows as value: …. Colors: true, false, other formula.

Timed properties

If the spec uses time bounds (S[a,b], S[<=n], Z/P/H variants), the log's last column is the event's integer timestamp, e.g. open,a,17.

Local tool: binds 127.0.0.1, serves only files under the repository, caps runs at 5000 events / 60 s. Full language reference: README.md.
